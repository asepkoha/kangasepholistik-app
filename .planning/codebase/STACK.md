# Tech Stack — Kang Asep Holistik

The foundational technologies and libraries used in the project.

## Core
- **React 18**: UI framework (Functional components, Hooks).
- **Vite**: Build tool and dev server.
- **JavaScript (ESM)**: Language (using `.jsx` for components).

## State & Data
- **React Context + useReducer**: Central state management via `useAppState`.
- **idb-keyval**: Simple IndexedDB wrapper for local persistence.
- **safeSet**: Custom storage safety layer for Quota protection.

## Styling & UX
- **Tailwind CSS**: Utility-first styling.
- **Framer Motion**: Smooth animations and transitions.
- **Canvas Confetti**: Celebration micro-interactions.
- **Lucide React**: Iconography.

## Audio & Media
- **Standard Audio API**: For Voice Note (VN) playback.
- **Google Fonts**: Modern typography (Inter/Roboto/Outfit).
